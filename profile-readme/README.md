### Selected work

**[Zollera](https://zollera.com)** — contractor quote analysis platform.
Ingests quotes as PDFs, photos, or scans and extracts structured, comparable line
items. Next.js 15 + TypeScript + PostgreSQL; 83 API routes, 61 pages. Tiered
multi-provider LLM extraction with failover, PII redaction, fraud-signal checks,
and an admin QC workflow. *Live in production — source is private.*

**[HighThree](https://highthree.org)** — federal retirement (FERS) analytics.
43 reference pages and 59 locality-pay pages. Year-by-year pension projection with
present-value discounting, break-even, claiming timing, and scenario comparison.
Vanilla HTML/CSS/JS, no build step, no server — every calculation runs client-side
so salary data never leaves the device. *Live in production — source is private.*

**[Flight delay prediction](https://dtsc691flightprediction-dhksswussxtnucdfkce3.streamlit.app)**
— MS Data Science capstone. 5,854,077 U.S. domestic flights joined to historical
weather across the top 100 airports; six models evaluated, LightGBM deployed on 71
pre-departure features. Reported honestly: test MAE 21.7 min, median absolute error
12.6 min, R² 0.077 — an earlier iteration scored far higher only because it leaked
post-departure fields such as `carrier_delay`, which I found and removed.
